# 考研模块 · 多专业大类扩展方案（大改，待确认）

> 状态：方案，未动代码。确认后才实施。叙事/参赛口径不变；本改在参赛仓库进行（用户已授权扩展）。

## 目标
把考研择校从「金融」单专业，扩展为可选「专业大类」的多专业择校工具，覆盖主流大类。

## 现状与改造面
- 数据：`school.x`(学硕)/`school.z`(专硕) 为金融硬结构；`national.json` 仅经济学门类线。
- 渲染/筛选/对比/报告大量硬编码：`金融专硕(0251)/金融学硕(0202)`、`431/396/数三`、`fProgram`(z/x)、`fMath`。
- 改造点：数据模型、专业选择器、科目/代码配置、国家线(多门类)、卡片/对比/报告/导出、搜索别名、时间线文案。约 982 行渲染器中 ~30 处硬编码。

## 方案 A（推荐）：专业维度化，金融平滑迁移
1. 模型：`school.programs = { fin:{x,z}, cs:{x,z}, mpacc:{z}, law:{z}, ... }`。旧 `x/z` 自动映射为 `programs.fin`，不破坏现有金融数据。
2. 配置表 `MAJORS`：每个大类的名称/代码/门类/默认科目/国家线门类键。如：
   - fin 金融(0251/0202, 经济学, 431+数三/396)
   - cs 计算机/电子信息(0854/0812, 工学, 408/自命题+数一/二)
   - mpacc 会计(1253, 管理学, 199管综+英语二)
   - law 法律非法学(035101, 法学, 398/498)
   - stat 应用统计(0252, 经济学, 432+数三)
   - mib 国际商务(0254, 经济学, 434)
3. UI：新增「专业大类」选择器；`fProgram`(学硕/专硕) 保留但随大类动态化；`fMath` 改为随大类的「初试科目」筛选；国家线页按门类切换。
4. 渲染/对比/报告/导出全部读「当前大类」，去除金融硬编码。

## 分期
- P1：模型+MAJORS 配置+选择器+金融迁移+全量回归（金融体验不变）。
- P2：试点 2–3 个大类，填头部院校（985/211/财经），缺失标「待核实」。
- P3：扩展更多大类 + 数据补全（长尾）。

## 数据与合规
- 新大类数据必须官方来源（研招网/各校招生目录），缺失留空标待核实，不编造（C5）。
- 采集量大：建议用户供官方目录 PDF/链接批量解析，或分批抓取。
- 不改动金融现有已对账数据；不引入构建链；保持纯静态。

## 风险
- 重构面广，需逐视图回归（查询/对比/国家线/报告/收藏/导出）。
- 新大类初期数据稀疏，需明确「待核实」展示，避免误导。
