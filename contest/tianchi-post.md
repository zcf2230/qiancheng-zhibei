# 前程指北 · 考研考公实习一站式信息助手（2026 Qoder 高校创造力大赛 · StudyHack 学习科研赛道）

作品链接：https://sanchalu-w5xdi6xev4t.qoder.website （Qoder Sites 部署，公开访问）

## 一、自我介绍

浙江工商大学金融学大三在读。和同届很多人一样，正站在考研、考公、实习的三岔口：三条路的信息散在研招网、公务员局专题站和几十家公司的招聘官网里，信息差和错过的窗口，比努力与否更能决定结果——于是有了这个把三条路放进同一个地方的作品。

## 二、作品是什么

一句话：给在考研、考公、实习之间做选择的大学生，把择校简章、岗位竞争度、网申时间线放进同一个网站，并用「路径决策」「统一时间线」「全局搜索」「三轨档案」「规划报告」五个跨路径工具帮你看清选哪条、什么时候动手、怎么落地。

## 三、为什么做

- 大三上的真实困境：三条路不是互斥选项而是时间窗博弈——考研报名、国考笔试、寒假实习网申几乎挤在同一学期，错过一个窗口就是一年。
- 信息可信度痛点：第三方汇总常常编造或过期数据。我的原则是官方优先、拿不准留空、第三方值标出处，空缺本身就是有效信息。
- 跨路径决策无人做：现有工具都只解决单条路（择校工具不管岗位，岗位工具不管网申时间线），没人回答「我该选哪条路、什么时间动手」这个真问题——这正是本站的产品定位。

## 四、怎么用（5 步）

1. 打开作品链接，首页点「路径决策」。
2. 答十道题（毕业诉求 / 学术兴趣 / 应试基础 / 时间投入 / 风险偏好 / 经济因素 / 地域 / 年级窗口 / 已有资源 / 五年画像），立刻得到主推荐路径 + 维度理由 + 备选 + 近期关键节点。
3. 点「统一时间线」，按考研 / 考公 / 实习筛选，看当前开放窗口与剩余天数（官方公告与推算分开标注）。
4. 用「全局搜索」一个框搜院校 / 招录机关 / 公司（如「北大」「税务局」「中信」），点击结果直达模块并自动定位；或进模块深查：择校分档、筛岗看竞争比、按倒计时排投递。
5. 在「路径决策」页底部填一份三轨档案（届别 / 专业 / 预估分 / 地域 / 数学），三个模块自动预填；决策页可一键生成可打印的三轨规划报告 PDF。

1. 架构交给 Qoder：全站采用「外壳 hash 路由 + iframe 沙箱」方案——三个业务模块以 iframe 嵌入统一外壳，样式与全局变量天然隔离、模块可独立演进；外壳负责导航、首页、路径决策与统一时间线。【截图：contest/shots/01-home.png 首页与导航】
2. 模块接入交给 Qoder：三个模块的数据与静态资源接入、相对路径适配、逐模块线上验证（考研 243 所院校卡、考公 1,861 个岗位、实习 1,064 家机构均通过）。实习数据以 AES-256-GCM 加密包管理，展示前一次性解密生成公开数据副本。【截图：contest/shots/04-kaoyan.png 考研模块、05-gongkao.png 考公模块、06-intern.png 实习模块】
3. 部署交给 Qoder：Qoder Sites 打包、发布、公开访问策略一次配置完成，评委点开即访问。【截图：Qoder Sites 发布状态】
4. 视觉统一交给 Qoder：一层 shared/hub-module.css 把三套设计变量归一（中性色 / 圆角 / 字体 / 主色青绿），三个模块共用同一套外壳语言。【截图：contest/shots/05-gongkao.png 统一视觉后的考公模块】

7. 跨路径工具交给 Qoder：构建期从三套数据生成 17,819 条全局搜索索引（含简称表与子序列匹配，「北大」正确置顶北京大学而非河北大学）；十题决策结果可一键生成三轨规划报告（打印/PDF，含三轨对照表）；「路径决策」页底部的三轨档案一次填写、三模块预填；「关于本站」页内置架构图与数据铁律。【截图：contest/shots/07-search.png 全局搜索、08-about.png 关于本站、03-path.png 十题决策与报告入口】
